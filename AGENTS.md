# AGENTS.md

## Project

AXTRACE Knowledge Base — личная база знаний на базе [Diplodoc](https://diplodoc.com/).

Подробный контекст проекта для LLM-ассистентов описан в `.ai-context.md`.

## Structure

- `docs/` - исходные markdown файлы документации
- `docs-html/` - сгенерированные HTML файлы, не редактировать вручную
- `scripts/` - скрипты для локальной разработки и пост-обработки
- `.yfm` - конфигурационный файл Diplodoc
- `package.json` - npm-скрипты и зависимости проекта

## Development

```bash
# Установить зависимости
npm install

# Запустить dev сервер
npm start

# Собрать статический сайт
npm run build
```

## Rules for AI agents

- Использовать YFM/Diplodoc-compatible Markdown.
- Не редактировать `docs-html/`: это результат сборки.
- При добавлении новой страницы обновлять соответствующий `toc.yaml`.
- При изменении структуры документации проверять ссылки и навигацию.
- Изображения размещать в `docs/_images/` с логичной структурой папок.
- Сохранять существующий стиль текста, если явно не попросили его изменить.
- Не делать лишний рефакторинг и не менять unrelated-файлы.
- Перед завершением структурных изменений запускать `npm run build`, если это возможно.

## Deployment

Деплой выполняется через GitHub Actions и GitHub Pages. Сгенерированные файлы публикуются из результата сборки Diplodoc.
